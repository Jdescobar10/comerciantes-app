🔐 Seguridad — Recomendaciones OWASP Aplicadas OWASP TOP 10
🔑 JWT en Memoria
Token JWT almacenado en NgRx Store en memoria. Nunca en localStorage ni sessionStorage. Protege contra ataques XSS.
🛡️ Auth Interceptor
auth.interceptor.ts agrega automáticamente el header Authorization: Bearer TOKEN en cada request HTTP protegido.
🚧 Route Guards
auth.guard.ts protege todas las rutas privadas. Sin sesión activa el usuario es redirigido automáticamente a /login.
🧹 Sanitización de Inputs
Angular sanitiza todos los valores interpolados (protección XSS). Reactive Forms con validadores estrictos incluyendo validador personalizado de fecha futura.
👤 Control por Rol
Acciones Eliminar y Descargar CSV solo visibles para rol Administrador. Rol obtenido del JWT y persistido en NgRx.
🔒 Build de Producción
Build optimizado con ng build --configuration production. Código minificado, tree-shaking aplicado. Compilado disponible en dist/comerciantes-app/.
